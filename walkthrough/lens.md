# Test the regexes in your code

A Test regex link shows above each regex in JavaScript, TypeScript, Python, Go, Rust, Java, Kotlin, C#, PHP and Ruby files. Click it and the panel opens beside your code with the pattern, its flags and its flavor.

In any other file, select a pattern and run Regex Preview: Test Selected Text as Regex from the editor's right-click menu. Cmd+Alt+M (Ctrl+Alt+M) opens the panel with the regex on the cursor line.

The link is a CodeLens and nothing more. There is no language server or TypeScript plugin, so hover, go to definition and errors in your language stay as they are.
